SwiftTerm v1.20.0, commit 5d14406844143538cd8f8851d2d8a67c1fe443e5
https://github.com/migueldeicaza/SwiftTerm
MIT license, included in Vendor/SwiftTerm/LICENSE.
OShell changes: a standalone package manifest and fixed build identity; 8 KiB PTY reads,
1 MiB receive backlog / 256 KiB resume threshold; skip scheduled redraws for detached tabs;
allow the host application to override remote clipboard requests.
OShell also makes focus notification overridable and reaps terminated PTY children off-main,
resetting their PID to avoid signalling a stale PID on repeated termination.
Main-queue receive batches yield after 1 ms. Exit statuses are decoded and Metal shader
libraries are shared per GPU device to avoid recompiling the same shaders for each pane.
The shared library cache is weak; live renderers own their libraries so closing the
last terminal releases the application cache. Grayscale/color glyph atlases start
at 512/256 pixels and retain their existing adaptive growth and maximum sizes.
PTY writes use a dedicated ordered DispatchIO stream channel on a duplicated master FD;
the read and write channels are separate and both are closed on termination.
PTY exit monitoring uses the child PID rather than the I/O running flag, so an earlier PTY EOF cannot suppress exit notification or child reaping.
The host can override key-down/key-up handling for explicit user-input synchronization, and select-all for copy-on-selection behavior.
A host-supplied, display-only foreground highlight hook is shared by the Metal and CoreGraphics renderers; selection colors retain priority.
PTY descriptors are marked close-on-exec so later sessions cannot retain another session's terminal.
PTY output-drained status includes EOF and queued deliveries. Backpressured reads
continue after child exit so short-lived local tools do not lose their final output.
On macOS, line-cell storage uses page-backed, size-classed slabs rather than the
process-wide malloc cache; empty slabs unmap immediately, including after reflow.
Allocation ownership follows BufferLine copies/resizes and is synchronized for
independent terminals. Other platforms retain their existing allocation path.
The host can clear optional shared CoreText/font/color drawing caches when idle.
Bounded live-cursor line text access supports prompt inspection independently
of the scrolled viewport, resolving wide cells and grapheme storage correctly.
The host can supply literal word-selection delimiters. Word selection and drag
extension follow those boundaries across soft wraps, including wide-character
continuations and the padding before a wrapped wide character.
