# 使用指南

## 会话与目录

选中会话后按 **⌘C** 复制配置，进入目标目录按 **⌘V** 粘贴；支持多选和右键菜单。粘贴生成独立会话，保留密码与连接参数，同名自动加“副本”，不会自动连接。快捷引用复制的是其源会话配置，粘贴到 `/Links` 也创建实际会话。复制仅在本次 OShell 进程的相同数据目录内有效，可跨窗口使用；退出程序或复制其他内容后失效，跨设备请使用导出/导入。搜索和改名输入框中的复制粘贴仍针对文字。

通过顶部“会话管理”或 **⇧⌘O** 打开会话列表。右键可以新建、编辑、复制、移动、删除、导入和导出会话；**Esc** 关闭弹窗。

列表和左侧会话栏使用相同的类型标识：SSH、SFTP、FTP 分别使用蓝色、绿色、橙色的 36 × 20 点圆角文字标识，紫色电脑表示本地终端；目录为金色文件夹。Link 快捷引用保留源会话的类型标识和颜色，在右下角加上青色链环角标；角标避开协议文字，悬停可查看目标会话类型及来源目录。颜色表示会话类型，不代表连接状态；悬停可查看类型说明。

选择单个会话、目录或快捷引用，按 **F2**（部分 Mac 键盘需要 **Fn+F2**），或右键选择“重命名”，即可在列表内修改名称；**回车**保存，**Esc** 或离开输入框取消。目录改名会同步更新整个子目录树，密码和连接参数不变。普通会话行最右侧的铅笔按钮打开完整属性；快捷引用打开链接属性，本地会话直接修改名称。`/Links` 根目录不可改名。

目录采用 Linux 风格，例如 `/生产/数据库`，根目录为 `/`。新建目录只填写一个名称，创建在当前浏览目录下；会话属性中的“目录”通过可展开的目录树选择。这属于会话分类，与连接页中的“文件初始目录”不同。

可拖动单个或多个会话、目录到目标目录行，或拖到 `../` 移至上一级；目录的子目录和会话会一起迁移。也可右键“移动到…”从目录树中选择位置。同名目录不会自动合并，目录不能移动到自身或其子目录。

右键会话目录选择“删除…”：空目录直接删除；非空目录先列出子目录、会话配置及快捷引用数量，确认“递归删除”后一次性删除。取消或按 Esc 不会改动配置。正在连接的标签继续保留，服务器文件不受影响。删除 `/Links` 子目录只移除其中的引用及实际存放于该目录的会话，不删除引用指向的目录外会话；`/Links` 根目录不可删除。

使用 **⌘ 单击** 多选、**⇧ 单击** 连选，点击“连接（N）”批量建立连接。右键选中项可选择“删除所选（N）…”，核对会话、目录和快捷引用数量后一次删除；取消或 Esc 不会改动配置。支持混合选择和搜索结果中的多选；目录递归删除，仅删除快捷引用会保留源会话。包含 `../` 或 `/Links` 根目录的选择不可删除。目录和 `../` 不参与批量连接。专用文件会话选择窗口保持单选。

“会话默认属性”只影响以后全新创建的会话配置，不会覆盖已有、复制或导入的会话。已有会话需打开其属性 → 保持活动 → 使用全局默认 → 保存，再重新连接，使 SSH 协议保活和 TCP KeepAlive 参数生效。SSH 协议保活是后台消息，不会在终端显示字符。

要让当前 SSH 连接立即启用空闲字符串，可右击标签 → 当前会话属性… → 载入全局空闲默认值 → 应用。空闲定时器在 SSH 认证成功后启动，不要求提示符包含主机名，也不要求安装 shell 集成；编辑命令、密码提示、全屏终端程序及文件传输期间仍暂停发送。

## 同一会话的隧道复用规则

同一份 SSH 会话配置在一个 OShell 进程的所有窗口中，只由第一条连接启用配置的本地、远程和动态隧道。再次连接、复制会话或新建分屏时，若已有连接正在建立或承载隧道，新连接自动跳过隧道；保存的规则保持不变。标签悬浮信息会说明本次连接的隧道策略。

隧道归属原 SSH 传输连接；如果复制的 SSH 渠道或 SFTP 仍在使用它，关闭原标签不会提前解除占用。原连接彻底结束后，下次新建连接会重新启用隧道，已打开的其他连接不会自动补建。不同会话配置仍各自启用自己的规则；其他程序占用端口时，仍会报告真实冲突。

## 共享代理与多级跳板

通过顶部“会话 → 代理管理…”新建、编辑或删除代理，也可以从会话属性的“代理”页进入。SSH 和 SFTP 会话只需选择共享代理；多个会话引用同一配置，修改代理后新连接采用新配置，已连接会话不会被重建。FTP 暂不使用该代理链路。

代理支持 SOCKS4、SOCKS4A、SOCKS5、HTTP CONNECT 和 SSH 跳板机。SSH 跳板可选择密码、私钥或自动 / SSH Agent；私钥只保存本机文件路径，私钥内容不会同步或导出，加密私钥的口令在连接时询问。每一级使用自己的用户名和凭据，密码依照 OShell 当前的本机加密或主密码方式保存。

“上级代理”表示连接当前代理时先经过哪个代理。例如 B 的上级为 A、会话选择 B，链路为 **本机 → A → B → 目标服务器**。最多 8 级，可以混合 SSH、SOCKS 和 HTTP CONNECT；不支持循环或缺失节点。SOCKS4 使用本机 IPv4 解析，SOCKS4A / SOCKS5 支持由代理解析域名。代理自身的地址必须能从它的上一级到达。

现有会话内的代理会迁移到统一的代理列表，保留原有代理 ID 和密码密文；不会按地址强行合并可能使用不同账号的代理。旧 `jumpHost` 字段保留兼容，可在代理管理建立对应链路后替换。删除代理前，需先调整仍引用它的会话或下级代理。

OShell 会话导出文件会包含所选会话依赖的代理链，导入时重新分配代理 ID 和加密凭据绑定，保留共享引用关系。包含共享代理的新导出文件使用第 4 版格式，需要支持该格式的 OShell 导入；不包含密码时会同时去掉会话与代理的密码。配置同步和主密码修改也包含代理凭据。参与共享的 Mac 都需要升级到支持共享代理的版本；旧客户端会拒绝新的代理引用格式，避免把它误当成直连配置。

## SSH 登录时保存密码

SSH 身份验证弹窗提供“连接成功后保存密码到会话配置”，默认不勾选。勾选后，只有收到 SSH 认证成功通知才加密保存；输入错误、取消或认证中断时不保存。已有会话更新其密码，临时会话会创建对应配置；未指定用户名时保存实际登录用户。

会话管理中的“复制会话”保留已保存的加密密码。修改副本的主机、端口或用户名后，密码留空且保留“保存密码”勾选时，会沿用原密码并按新目标重新加密；原会话不变。输入新密码可替换，取消勾选可清除副本的密码。

会话属性及 SSH / FTP 登录输入框提供“显示密码”，只显示本次手动输入的内容。已保存密码不会自动填入或解密回显，重新打开属性时默认隐藏；保存或取消后会清空本次输入并重置显示状态。

已设置 OShell 主密码时继续使用主密码保护，否则使用 OShell 本机密钥加密，不使用系统钥匙串。下次打开或重连会话可读取已保存密码。密钥口令、验证码、其他跳板机提示和堡垒机一次性凭据不作为当前会话登录密码保存。认证过程中若会话被删除或连接信息发生变化，会提示未保存，不覆盖新配置。

## 快捷链接 /Links

添加已有会话快捷引用时，使用带搜索框的目录树选择源会话，可全部展开 / 收缩。目录只用于导航，选中会话后下方显示协议、主机端口和目录；点击“添加”、双击或回车确认，仅创建引用，不连接服务器。

会话管理中的 `/Links` 是快捷引用和快捷目录的统一入口，与顶部快捷链接栏同步。已有快捷链接会自动出现在这里，原会话的位置、密码及连接配置不变。

- 点击链接栏最左侧的“添加到链接栏”按钮，为当前选中的会话直接创建 `/Links` 快捷引用，自动使用会话名称，无需填写名称或选择目录；按钮固定显示，不随链接横向滚动。也可在原会话或终端标签上右键“添加到快捷链接…”，或在 `/Links` 中右键“添加已有会话链接…”。
- 链接栏空白处右键可添加当前会话链接、新增文件夹、打开 `/Links` 会话目录或隐藏链接栏。拖动链接或文件夹到插入线位置可调整顺序；拖动链接到目录中央高亮处可移入目录。打开目录后，按住其中的链接可拖回链接栏插入线或末尾空白处，也可拖到其他目录；子目录和右侧“所有快捷链接”菜单中的链接同样支持。顺序会保存，重复引用不会覆盖。
- 从会话列表拖入 `/Links` 会创建引用；拖入普通目录会保留源目录，并在 `/Links` 下创建引用目录树。
- “链接属性…”修改引用名称和位置；“源会话属性…”修改实际连接配置。所有引用使用原会话的最新配置。
- 引用及其目录只能在 `/Links` 内移动，`/Links` 根目录不可重命名或删除。删除引用不会删除原会话；删除原会话会清理失效引用。
- 导出全部会话或 `/Links` 目录会包含引用关系及所需源会话。带引用的导出文件使用格式版本 3，需要 OShell 0.2.51 或更新版本导入；仍兼容旧会话文件。

## 多窗口

右键点击 macOS Dock 中的 OShell 图标，选择“新建窗口”可打开独立窗口；所有窗口关闭、应用仍运行时也可使用。

通过“会话 → 新建窗口”或 **⇧⌘N** 打开独立 OShell 窗口，也可从“窗口”菜单新建。此快捷键可在设置中自定义。

各窗口独立管理标签、分屏、标签组、同步输入与快速发送。“本窗口全部会话”只向所在窗口发送。菜单栏操作跟随当前窗口；会话配置、快捷链接、快速命令和应用设置在所有窗口间同步。

按住标签标题拖到所有 OShell 窗口之外的空白处松开，即可自动创建新窗口，将整个标签页及其中的分屏移入，保留连接与输出历史，无需重新登录。窗口会出现在松开鼠标的屏幕内。按 Esc 取消拖动不会创建窗口；窗口内拖动排序、分屏或合并保持原有行为。最后一个标签也可以拖出；迁移后原窗口没有会话标签时自动关闭，已打开的文件管理窗口转由目标窗口管理，连接和传输继续。

将标签标题拖到另一个 OShell 窗口的标签栏，看到插入标记后松开，可移动到该窗口的指定位置；分组标签栏和空窗口也可接收。整个标签及其中的分屏、连接和历史一起迁移，原窗口其他会话不受影响；移走最后一个标签后原窗口自动关闭。Esc 取消拖动；拖到所有 OShell 窗口之外的空白处仍会新建窗口。

跨窗口迁移标签时，也可直接拖到目标窗口的终端页面或其他内容区。拖到某个标签组页面时合并到该组；拖到其他内容区时合并到当前组。悬浮显示合并预览，拖到页面边缘也只合并，不额外分屏；标签栏仍可指定插入位置。

也可右键标签选择“移动到新窗口”。迁移时会从原窗口的同步输入和发送目标中移除。当前有文件选择附属弹窗时，请先完成或取消选择。

关闭窗口只结束该窗口的连接和文件操作，有活动连接时需要确认。关闭最后一个窗口后应用继续运行，可用 **⇧⌘N** 或点击 Dock 图标重新打开；**⌘Q** 退出整个应用时统一确认所有窗口。主密码解锁状态和更新服务由应用共享；新建窗口不会重复要求输入主密码或启动多个更新服务。

## Emoji、图标与宽字符

“设置 → 文字”提供 Emoji / 中文 / 全角 / 主题图标混排预览。默认优先使用 macOS 系统彩色 Emoji，中文和全角字符自动占两列，缺失的主题图标使用内置补全字体；彩色 Emoji 的具体覆盖范围取决于当前 macOS 字体。明确指定文本样式的符号仍保持单色，原始文字和复制内容不变。

可按需要开启“模糊宽度字符使用双列”，适用于采用 CJK 宽度规则的远端环境；此设置影响希腊字母、部分符号及私用区图标等，不是启用中文显示的前提。宽度设置只用于新建终端，避免改写现有历史、光标和 TUI 布局；彩色 Emoji 偏好即时应用。ANSI、256 色和 24 位真彩色继续按程序输出的颜色序列显示。

## 终端本机时钟

在“设置 → 时钟”开启“显示本机时钟”，选择四角、四边居中或正中间位置。默认关闭，默认位置为右上角；应用后所有已打开和新建的终端均生效，无需重连。

时钟按当前 Mac 的时区显示 `yyyy-MM-dd HH:mm:ss`，每秒更新。可独立选择本机字体、8–96 点字号、字体颜色和 0–100% 透明度（默认 50%；0% 不透明，100% 完全透明）。颜色可跟随终端文字或自定义；字体不可用时回退为系统等宽字体。时钟以无背景浮层覆盖在终端文字上方，较窄的分屏中会缩小显示以容纳完整时间。设置页提供文字叠加预览，点击“应用”后即时更新所有终端，取消不保存。它不读取远端时间，不进入终端输出、复制内容或会话日志，也不拦截点击、选择、滚动和拖放。所有可见终端共用刷新计时器，隐藏标签 / 分屏停止订阅，关闭全部终端或关闭时钟后停止计时器。

## 专注全屏

使用 **⌃⌘F**、顶部“工具 → 专注全屏”、菜单栏“视图 → 专注全屏”，或标签右键菜单进入。只显示标签栏及下方内容：隐藏窗口标题、顶部工具栏、链接栏和提醒栏，保留终端分屏、快速发送栏及已打开的撰写窗。菜单栏与 Dock 在全屏时自动隐藏。

再次按 **⌃⌘F**（或自定义的专注全屏快捷键），也可通过菜单退出，恢复普通窗口与原来的显示配置；连接和分屏不重建。**Esc 不退出专注全屏**：弹窗或终端搜索正在打开时，Esc 关闭当前弹窗 / 搜索；输入法正在组词时先交给输入法处理，其余情况保留终端和输入控件原有的 Esc 行为。快捷键可以在设置中自定义，各窗口的全屏状态相互独立。

## 快速定位会话

使用 **⌥⌘O** 或“会话 → 快速切换 / 连接会话…”打开搜索面板。可按主机名、IP、账号、端口、会话目录或标签组名称搜索；用空格分隔多个关键词，↑↓ 选择，回车打开，Esc 取消并返回原输入位置。

“已打开终端”列出当前窗口的各个终端分屏，包括隐藏标签组中的会话。选择后定位原连接，不重复登录；“已保存”使用保存的配置新建连接，也支持 SFTP / FTP。面板只搜索会话信息，不搜索密码和终端输出。搜索结果较多时显示前 200 项，继续输入可以检索到列表外的会话。

## 标签与分屏

标签标题悬停约半秒后显示可操作的信息卡，移入卡片可点击各字段右侧的复制按钮，也可复制全部或查看完整连接详情。主机 IP 是当前主机上报的信息，连接 IP 是本机观察到的 TCP 对端（代理、跳板场景可能不同）；未获取的字段不能复制，未配置的 SSH 用户名不会猜测。分屏标签显示当前活动分屏；悬浮信息卡不抢走终端键盘焦点，点击标签、拖动或切换窗口时关闭。


分屏后的标签标题汇总各终端：例如“开发机 ×2”或“开发机 | 数据库”。超过两个不同标题时用“+数量”表示其余终端，悬停可查看完整列表和当前分屏。标题按分屏顺序排列，不随焦点来回变化；关闭到一个终端时恢复其标题。每个终端仍遵循自己的标题识别方式。

一个标签只有一个终端时，不再重复显示终端内的会话小标题，内容直接接在标签栏下方；分屏时显示各分屏标题和关闭按钮，合并或关闭到单个终端后自动收起。

头部栏的“当前会话属性”图标打开所选 SSH 会话的完整配置，保存到会话管理，供以后新建连接使用；“默认会话属性”图标设置新建会话的默认值。鼠标悬停可查看按钮名称。空白/本地标签不能编辑 SSH 属性，当前连接的空闲保活仍可从标签右键“当前会话属性…”即时调整。

“分屏”图标菜单可新建左右或上下终端分屏，使用当前会话配置创建新的终端。窄窗口会将部分工具按钮收紧为图标，仍可悬浮查看名称。

按 **⇧⌘Enter** 临时放大当前标签内的一个终端分屏，再次按下恢复原分屏比例。其他会话继续运行；放大时可用 **⌥⌘] / ⌥⌘[** 循环切换下一个 / 上一个分屏。以上操作也在“分屏”按钮和“视图”菜单中；标签右键菜单支持放大 / 恢复。关闭放大的分屏或新建分屏时会恢复布局。

放大只改变显示范围：“可见会话”发送目标只包含实际可见的终端，“全部会话”“当前标签”等发送范围仍包括临时隐藏的分屏。新快捷键可在设置中修改；如果与已有自定义快捷键相同，会优先保留原配置。

同一标签内有多个终端时，点击分屏右上角的 **×** 可单独关闭该会话，也可先选中分屏再按 **⌘W**，或从标签右键菜单选择“关闭当前分屏会话”。关闭仍在运行的会话会要求确认；其余分屏保持连接并自动填补空位。标签标题上的 **×** 和 **⇧⌘W** 仍关闭整个标签及其全部分屏。

- 每个分屏窗口内的标签分别从 1 连续编号，关闭标签后只调整所在分屏的编号。编号快捷键以当前选中的分屏为范围；合并分屏后重新统一编号。
- 拖动标签到终端区域四边创建分区；拖到另一组中央或标签栏合并。
- 点击任意终端内容区即可将键盘焦点切换到该分区，无须先点击标签标题。
- 拖动分隔线调整大小。排列菜单提供单组选项卡、水平、垂直、瓷砖模式。
- 大量标签排列超出窗口时，可用滚动条或触控板横向手势浏览；终端历史滚到边界后，滚轮继续滚动外层区域。按住 **Option** 滚动可直接移动排列区域；仅左右溢出时普通鼠标滚轮也可左右浏览。
- “复制会话”使用相同配置建立独立连接；“复制 SSH 渠道”在当前已认证传输上建立独立终端，不重复认证。
- 标签右键可将会话加入顶部快捷链接。后台输出通过标签圆点和加粗标题提示。
- 拖动标签标题可调整顺序，焰橙色竖线提示插入位置，松开后生效；标签过多时靠近两侧自动滚动。各分屏 / 分组内独立排序和编号，也可拖到其他可见分组的标签之间。连接、分屏内容及终端历史保留；拖入终端内容区仍执行原有分屏或合并操作。文件管理的标签同样支持拖动排序。
- 标签栏任意区域均可右键打开操作菜单：标签及其关闭按钮针对该标签，空白处、“+”、分组按钮和列表按钮针对所在分组的当前标签。菜单提供新建标签 / 分组 / 窗口、会话管理、复制会话 / SSH 渠道、移动、分屏、排列、专注全屏、重连、关闭和属性设置；没有可用目标时相关项目置灰。
- `+` 新建空白标签，提供 `OShell >` 网络工具提示符；“本地”或 **⌘T** 打开本地终端。
- 当前选中的终端已退出并回到 `OShell >` 时，从会话管理、快捷链接或外部客户端连接新会话会直接复用此位置；空白标签同样可用。分屏时只替换当前选中的空闲终端，保留标签编号、分组和其他分屏。正在连接、运行本机工具或传输文件时仍新建标签；批量连接仅第一个终端会话复用空闲位置，其余分别新建标签。
- SSH 退出后保留终端和历史，输入 `exit` 或 `quit` 只关闭当前会话；关闭最后一个分屏时才关闭标签。网络工具可通过 `help` 查看。
- 标签标题前的绿色圆点表示连接正在建立或保持连接，红色圆点表示未连接 / 已断开；悬浮提示显示具体状态。分屏标签以当前选中的终端为准。未读输出仍通过标题加粗和列表提示显示，不改变连接状态圆点的颜色。
- 在 `OShell >` 中输入 `ssh` / `telnet` 建立的交互连接同样显示绿色，悬浮提示为“命令行连接运行中”；退出、取消或连接失败后恢复红色。`ping` 等普通网络排查命令不改变连接状态点。
- 只有已连接的会话（SSH 已完成认证，或本地终端正在运行）允许双击新建相同会话。断开、空白标签、连接建立中和等待认证时，双击不执行操作；有效堡垒机通道继续复用，失效通道不弹窗、不新建连接。

## 自定义标签组

顶部“标签组”可新建、重命名、隐藏/显示指定组，也可仅显示某一组或恢复全部组。每组标题左侧的分组菜单提供相同操作。自定义名称和显隐状态只在当前窗口有效，不改变会话管理目录或 `/Links`。

- 标签右键“移动到标签组”选择目标，也可拖入已有分组，包括空分组。连接中或已连接的 SSH 会话会保留同一连接、终端内容和日志状态。
- 移入隐藏组后，该组保持隐藏；隐藏期间继续接收输出并保持连接，顶部“标签组”会提示隐藏组的新输出。
- 快速发送的“本窗口全部会话”仍包含隐藏组；“可见会话”不包含隐藏组。普通标签切换快捷键会跳过隐藏组，通过标签组菜单可主动显示并切换过去。
- 具名空组会保留，便于继续添加会话。每组编号独立从 1 开始，关闭标签后在本组补号。
- 水平、垂直、瓷砖排列会保留具名分组及显隐状态。“解散分组（保留会话）”将标签交给其他组；“合并为单组选项卡”显式取消全部分组，两者均不会重连。

## 输入与外观

“设置 → 选择”可指定双击选词的分隔符，每个字符按字面生效，不使用正则表达式或转义写法。空格等空白始终作为边界，分隔符留空时只按空白选择。默认保留路径中的 `/`、主机名中的 `.` 和 `-`，便于复制完整路径及地址；“重置”恢复默认分隔符，点击“应用”才保存。

普通双击按分隔符选词；勾选“Shift + 双击按分隔符而不是空白选择”时，Shift+双击采用相同规则，取消勾选则选取空白之间的整段文本。分隔符与 Shift 方式仅保存在当前 Mac，不写入共享配置；应用后所有现有及新建终端立即生效。自动复制和复制去除头尾空白也在“选择”页，继续使用原有配置。远端 TUI 启用鼠标上报时保留其鼠标操作，Shift 绕过上报仍遵循终端规则。

`OShell >` 本机工具提示符提供常用的 Shell 行编辑操作：

| 操作 | 快捷键 |
| --- | --- |
| 行首 / 行尾；前后移动一个字符 | Ctrl+A / Ctrl+E；Ctrl+B / Ctrl+F 或左右键 |
| 上一条 / 下一条历史 | ↑ / ↓ 或 Ctrl+P / Ctrl+N |
| 反向搜索历史 | Ctrl+R，然后输入关键词；重复 Ctrl+R 查找更早匹配，Ctrl+S 查找较新匹配 |
| 确认 / 取消搜索 | Enter 执行匹配命令；Esc 接受结果继续编辑；Ctrl+G 取消并恢复原草稿及光标 |
| 删除光标前 / 后内容 | Ctrl+U / Ctrl+K |
| 删除前一个词；恢复最近一次删除 | Ctrl+W；Ctrl+Y |
| 前 / 后移动一个词 | Option+B / Option+F，或 Ctrl+左右键（按空白分词） |
| 删除前 / 后一个词 | Option+Backspace / Option+D |
| 交换光标前后字符（行尾交换最后两个） | Ctrl+T |
| 清屏并保留输入 | Ctrl+L |
| 补全命令名称 | Tab；多个候选先补全共同前缀，再按 Tab 列出候选 |
| 取消当前输入；空行关闭当前会话 | Ctrl+C；Ctrl+D（非空时删除光标处字符） |

搜索区实时显示关键词和匹配命令；没有匹配时会明确提示，按 Enter 不执行旧结果。搜索支持中文，长关键词会在一行内截取显示。Option 组合键要求终端启用 Meta 输入；也可以先按 Esc，再按对应字母（搜索状态下的 Esc 用于接受结果）。

历史最多 100 条，仅保存在当前分屏内存中，向下越过最新历史会恢复原草稿；不会读取服务器的 Shell 历史，也不记录进入 SSH 等工具后输入的密码。Tab 只补全内置支持的命令名称，不补全参数或文件路径。`OShell >` 是本机网络工具入口，不解析管道、重定向、变量或 Shell 脚本；需要完整 zsh / bash 环境时，请打开“本地终端”。

快速发送栏支持“当前分组”和“选择分组…”：前者跟随当前选中的标签组，后者可勾选一个或多个组（含隐藏组）。组内全部可输入的会话及分屏都会接收，新加入或移出的会话自动更新；登录、传输等暂不可输入的会话会跳过。没有自定义标签组时，所有标签属于默认分组。发送模式会记住；具体分组仅在当前窗口保留，重启后需重新选择，分组删除后也不会改发到其他组。

快速发送栏和撰写窗可以发送到当前、全部、可见或指定会话；同步输入会把键盘输入同步到所选终端。发送范围会记忆，手动指定的目标在重启后需要重新选择。快速发送 `exit` / `quit` 关闭标签时，输入焦点保留在快速发送栏，直到主动切换输入位置。

选中复制、鼠标右键粘贴和多行粘贴确认可在设置中调整。多行粘贴预览底部可勾选“下次不再使用预览”，确认粘贴后会关闭设置中的预览选项，取消则不修改；可随时在设置 → 常规中重新开启。复制可独立启用“删除头部空白”和“删除尾部空白”（默认关闭），手动复制和选中自动复制均生效；仅清理整段选区边界的空格、制表符及换行，保留中间各行缩进。Shift+右键保留终端菜单。主题、终端配色和突出显示集分别配置，不会重建现有连接。

在“设置 → 常规 → 终端字体”中可选择 **DejaVu Sans Mono（内置）**，支持常规、粗体、斜体和粗斜体。应用后所有已打开的终端即时生效，重启后保留选择，无须安装系统字体。中文等未覆盖字符使用系统字体回退。

OShell 内置 Nerd Fonts 符号回退，默认等宽字体即可显示常见 Oh My Zsh / Powerline 提示符图标，无须安装系统字体。已选字体自带的图标优先保留；Shell 主题本身仍由本地或远端 Shell 配置。

在“设置 → 标签”选择新建会话的默认标题方式，初始为“仅显示会话名称”。“同时覆盖所有已有会话和已打开终端的标题方式”默认勾选：点击应用后立即统一已有会话与当前标签的标题，无需重连；取消勾选则只影响以后新建的会话。已有会话与导入会话在未覆盖时保留原识别方式，复制会话继承本机标题选择。

也可在“会话属性 → 标签与快捷连接 → 标题识别方式”中单独选择并保存：

- **仅显示会话名称**（新建默认）：标题使用保存的会话名称，不随远端提示符变化，不主动探测；已识别的主机信息保留在悬停详情中。保存会话改名后，已打开的名称标题同步刷新。

- **允许主动探测主机名/IP**：在空闲提示符处执行探测命令，可能写入远端历史；收到 Shell 集成上报后停止主动探测。
- **不主动探测，只展示主机名**：只读取提示符、OSC 0/2 标题和 OSC 7 目录；不执行探测，也不采用集成脚本的主机信息上报。
- **接受 Shell 集成上报**：优先使用 [Shell 集成](../shell-integration/README.md) 上报信息；未配置脚本时退回被动识别，不注入探测命令。旧会话开启过主动探测的，会保留该选择。

本地终端使用名称模式时显示会话名称；使用主机识别模式时优先显示 macOS 配置的本地主机名（LocalHostName）；系统运行时主机名受 VPN/DNS 环境影响时，仅把本机已知别名归一到本机名称。远程 SSH 主机名不会一律截断域名，在本地终端内 SSH 到其他主机后仍按远程上报更新标题。

名称模式显示会话名称，其他三种模式显示主机名；编号和状态标识沿用原有选择，IP、端口等不占用标题空间。鼠标悬停标签可查看分组详情：当前主机名/IP，以及初始 SSH 连接的会话名称、配置地址、端口、用户、实际连接 IP/端口和连接状态。实际连接地址来自本机 TCP 对端，可能是代理或堡垒机，与内层跳转后的主机 IP 分开显示；无法确认时标注未获取，不通过 DNS 猜测。FTP/SFTP 文件管理标签沿用原显示方式。

上述标题选择与全局默认保存在本机 `tab-title-settings.json`，不写入共享配置，不参与同步或导出（即使勾选“客户端设置”同步）。原共享协议中的三种识别值保持兼容。空白标签和命令行临时连接继续显示当前状态。

设置 → 关于可查看版本、构建号、当前架构和最低系统要求，并打开开源许可证及第三方声明；配置更新仓库后也可打开项目主页。

## 文件传输

文件管理窗口按 **Esc** 最小化，保留文件标签、连接和传输；按 **⌘W** 关闭整个文件管理窗口，正在传输时会先确认。内部菜单、文件选择和确认弹窗仍优先处理 Esc。终端中的 Esc 保持 Shell / Vim 等程序的原有行为。

顶部工具栏提供独立的“文件管理”按钮，位于“本地”右侧；窄窗口时显示文件夹图标，悬浮可查看名称。“工具”菜单中的入口继续保留。

文件管理窗口底部提供“限速”选择：默认不限速，可选常用档位或自定义 KiB/s、MiB/s（0 为不限速）。每个文件标签独立设置，作用于该标签的上传和下载；切换标签保留其限速，重新打开的新标签默认不限速。SFTP / FTP 在传输过程中调整立即作用于后续数据，无需重连；SCP 兼容传输在开始时读取上限，运行中修改用于下次传输。SFTP / FTP 状态栏同时显示已传大小和当前速度，速率按文件内容计算，系统缓冲可能造成短时波动。

文件列表以图标区分目录、符号链接、文本、代码、脚本、配置、压缩包、图片、音视频及常见文档等类型。普通文件按名称和扩展名识别，仅作为显示提示；服务器未提供类型时显示“未知”，不会读取远端文件内容来生成图标。

列表还展示权限、所属用户和组：权限显示 Linux 风格字符与八进制数（例如 `-rw-r--r-- (0644)`）。SFTP 优先显示服务器提供的用户名、组名，否则显示 UID/GID；FTP 使用 MLSD 的 UNIX 扩展属性或 UNIX LIST 信息，缺失字段显示“—”。列宽可拖动调整，窄窗口可横向滚动查看全部属性。

从已连接的 SSH 终端选择“文件管理”或拖放上传时，SFTP 使用该终端已认证的 SSH 连接，无需再次输入登录密码。文件标签复制、重连和 SCP 传输也保持复用；关闭原终端不会中断仍打开的文件标签，最后一个使用者关闭后释放连接。

服务器或堡垒机必须允许在该连接上开启 SFTP 子系统。若连接失效或 SFTP 被拒绝，会明确报错，不自动新建连接或重试一次性口令。这里复用的是 OShell 最初建立的 SSH 连接；在终端内手动再次执行 ssh 跳到其他主机，不会自动改变文件管理的目标。

SFTP 与 FTP 使用会话管理中的协议分类，文件窗口支持多个标签。可拖放上传、右键下载；SSH 文件会话可选择 SFTP 或 SCP。FTP 是普通 FTP，不包含 FTPS，敏感连接请优先使用 SFTP。

远端安装 lrzsz 后，可使用 `rz` 上传和 `sz filename` 下载。会话右上角的紧凑卡片显示真实进度、已传大小和速度，可随时取消；卡片不会改变终端行列数。取消或中断后可能保留部分下载文件。在 `rz` 上传选择窗口中取消、尚未选择任何文件时，只取消本次上传，保留当前 SSH 连接，可继续输入命令或重新执行 `rz`。

## 密码与更新

头部栏右侧提供“更新”按钮：点击检查新版本，发现更新后弹出升级确认窗口，由用户选择是否下载安装；已下载但暂缓安装时显示“安装更新”。检查期间禁止重复点击，网络失败会显示原因；未配置更新仓库时先进入更新设置。

更新设置继续填写 `owner/repo` 或 GitHub 仓库地址。新版从对应 GitHub Pages 站点读取签名更新信息，安装包仍从 Releases 下载，不需要登录 GitHub 或配置 Token。维护者需启用静态更新站点；未部署时会给出明确提示。重复检查会短暂使用缓存，网络失败后等待再重试。

主密码及本机保存方式见 [安全说明](../SECURITY.md)。可从 OShell 菜单设置、修改或清除主密码。未设置时的风险提示可点击“我已知晓，不再提醒”永久隐藏，此选择不改变密码保护策略。

### 使用 Touch ID 解锁

在已设置主密码的 Mac 上，打开“设置 → 安全”，勾选“在此 Mac 使用 Touch ID 快捷解锁”并点击“应用”，输入当前主密码完成启用。取消设置不会保存此开关。之后打开启动解锁弹窗或锁定密码后的解锁弹窗，会自动发起一次 Touch ID 验证，无需先点击按钮。密码框仍可使用；手动输入、提交或关闭窗口会取消指纹请求。取消或验证失败后保留密码输入，不自动反复弹出，也可点击“重试 Touch ID”。

主密码经 Secure Enclave 保护后以加密记录保存在本机私有目录，只有验证当前指纹后才能解密；SSH / FTP / 代理密码仍保存在 OShell 配置中。每台 Mac 单独启用，不随 iCloud / WebDAV 同步。改主密码、清除主密码或变更指纹后需要重新启用；停用时取消勾选并点击“应用”，会删除本机记录。旧钥匙串记录会尝试无提示迁移；无法访问时，先手动输入 OShell 主密码，再关闭并重新开启 Touch ID 一次。新记录无需在每次升级后授权钥匙串。

需要支持 Touch ID / Secure Enclave 的 Mac，以及现代版或 macOS 11+ 通用版 OShell；macOS 10.13 构建继续使用手动主密码。导入 / 导出文件仍使用文件对应的密码，不会以本机 Touch ID 代替。

在设置的“更新”页填写公开 GitHub 仓库，例如 `owner/repository`。未配置时不检查网络，自动检查默认关闭。安装前会确认关闭活动终端；取消后可以从菜单继续安装已下载更新。

## 堡垒机启动器

兼容启动器位于应用包内：

```text
/Applications/OShell.app/Contents/MacOS/OShell-ZOC
/Applications/OShell.app/Contents/Helpers/OShell-FileZilla.app/Contents/MacOS/OShell-FileZilla
```

它们分别兼容 ZOC 风格终端参数与 FileZilla 风格文件会话参数，并不是对应第三方软件。具体堡垒机的参数约定可能不同，应使用测试资产验证。临时票据不会自动存入会话库；不要把包含密码或票据的完整启动参数贴到公开 Issue。

## 自定义快捷键

打开 App 设置的“快捷键”页，选择功能后点击“录入快捷键”，按下组合键；Esc 结束录入。也可通过 Command、Option、Control、Shift 勾选框和按键列表指定组合，便于检查会被系统截获的按键。点击“设为此快捷键”暂存，最后点击整个设置窗口的“应用”保存并立即生效；取消不会改变已保存绑定。

可清除单项、恢复所选默认或恢复全部默认。下一个/上一个标签的默认兼容组合也属于同一功能，自定义或清除后不再保留旧组合。菜单同步展示主要快捷键，完整默认组合在列表中显示。

OShell 按物理键位处理快捷键，本页配置优先于系统的应用菜单快捷键设置。普通文字、单独 Shift 和裸 Esc 不可绑定；F1–F20 可单独绑定，其余按键需包含 Command、Option 或 Control。自定义组合会优先于终端输入，例如将 Control-C 用作应用功能后，它就不再作为终端中断字符发送。

检测覆盖应用内部重复绑定、macOS 公开接口返回的已启用系统快捷键、可读取的系统应用菜单快捷键，以及切换应用、强制退出、锁屏和文本编辑的常用保留组合。冲突会阻止指定或应用；可点击“重新检查系统冲突”刷新。读取失败会明确提示，第三方应用自行注册的全局快捷键无法完整检测。“未发现已知冲突”不代表其他软件一定没有占用。OShell 不会修改系统快捷键设置。

## 从其他终端客户端迁移

会话管理右键“导入会话到当前目录…”支持选择 SecureCRT、Xshell 或 OShell 来源。第三方导入会先预览，保留目录和原有会话，不自动连接。完整步骤和迁移范围见 [SecureCRT / Xshell 会话导入教程](session-import.md)。

其他客户端导出的配置可借助 AI 编写脚本，转换为 OShell 原生会话 JSON 后导入。文件格式、字段映射、脚本提示词和校验流程见 [其他终端会话转换指南](session-conversion.md)。

## 终端字体

设置 → 常规中的“历史行数”保留预设，并提供“自定义…”选项，可填写 500～100000 的整数，默认 3000。点击应用后对已打开终端生效，无需重连。历史按终端分别占用内存，行数过多、多会话和宽窗口会增加内存压力，可能使搜索与窗口缩放变慢，严重时可能因内存不足退出；超过 20000 行会突出显示提示。降低上限会丢弃较旧的历史，长期留存输出建议使用终端记录文件。

在“设置 → 常规 → 终端字体”中选择字体。列表按当前 Mac 实际可用的字体动态生成，区分系统字体和已安装字体，并将等宽字体放在推荐分区。不同 macOS 版本及本机安装情况会影响可选列表。

选择时可预览英文、数字和中文；非等宽字体会提示可能影响字符对齐。点击“应用”后更新已打开的终端，无需重连。DejaVu Sans Mono 和 Nerd Fonts 图标补全仍随应用提供。未安装的已保存字体暂时回退到系统等宽字体，打开设置不会自动改写原字体配置。

### /Links 中的实际会话

`/Links` 及其子目录可同时保存快捷引用和实际 SSH、SFTP、FTP 会话。右键目录空白处选择“新建 SSH / SFTP / FTP 会话”可直接创建实际会话；选中已有实际会话后，用“移动实际会话到…”将配置迁入或迁出。

原有“添加快捷链接”和从普通目录拖入 `/Links` 的操作继续创建快捷引用，保留原会话位置。实际会话已经位于 `/Links` 时，拖动会移动该会话本身。顶部链接栏同步展示两类项目，可点击连接、拖动排序或移入目录；会话图标表示实际会话，链接图标表示快捷引用。

删除快捷引用不会删除源会话；删除实际会话会移除指向它的快捷引用。已连接的终端继续运行。

## iCloud、自定义同步目录与 WebDAV

同步目录和 WebDAV 统一使用**本地加密副本 + 共享同步副本**。正常运行时始终读写 `~/Library/Application Support/OShell/configuration.json`，不会把 iCloud 文件当作工作数据库。共享目录不可用、文件还未下载或 WebDAV 离线时，仍可使用本地会话并保存修改。

同步方式都**强制设置主密码**，已有本机密钥保护的密码需先转换为主密码保护。同步策略可以按设备分别设置，不参与共享。

同步内容分为四类：

- **会话资料（默认开启）**：会话、目录、快捷链接（内容与顺序）、关联代理及加密密码作为整体同步。
- **客户端设置与高亮规则（默认关闭）**：主题、字体、通用快捷键、终端行为、历史行数、时钟、配色与高亮规则，以及链接栏显示开关。规则随设置一起同步，保留引用关系。
- **快速命令（默认关闭）**。
- **默认会话属性（默认关闭）**。

未勾选的类别不会上传本机值，也不会将远端值应用到本机；远端原有字段会完整保留，新目标使用协议默认值。更改勾选范围后只重置本机比较基准，下次接入已有共享数据会重新确认，不删除远端数据。客户端设置中的更新来源、自动更新选择和安全提醒确认仍保留本机；Touch ID、同步凭据、数据目录、同步策略以及平台专属本机设置不上传。

同步时机可选择：自动或仅手动、启动并解锁后同步、检查间隔、修改后等待时间和失败重试间隔。默认保持原有行为：自动、启动检查、每 60 秒检查、修改后等待 2 秒、失败后 60 秒重试。检查和重试间隔支持 15–86400 秒，填 0 可关闭；修改后等待支持 1–300 秒，连续修改会合并为一次同步。仅手动模式不会安排自动任务。关闭失败重试后，失败会暂停自动尝试，需手动重试；冲突始终需要选择，不自动覆盖。

同步文件仍使用 AES-256-GCM 加密及既有 v2 格式，字段结构没有变化，与 oshell-desktop 的配置和凭据互通。上述范围控制仅在 OShell 实现；未修改的 Desktop 仍按其现有逻辑处理共享字段，不能认为它也具有相同的策略开关。

共享副本不包含本机解密密钥、SSH 私钥、主机信任记录、下载文件或终端输出。本机完整配置仍照常保存所有设置，不能将会话投影覆盖本机配置文件。

### iCloud / 自定义同步目录

先打开“设置 → 多设备同步”，在“同步方式”中选择 **同步目录（iCloud / 自定义目录）**，然后配置目录：

1. 点击“选择文件夹…”。第一台 Mac 选择专用空文件夹；其他 Mac 选择已存在加密 `configuration.json` 的目录，程序会自动识别，无需区分新建与连接入口。
2. 点击“应用”，按提示设置或解锁主密码。普通目录切换立即生效，无需重启，当前终端连接不关闭。首次接入已有数据仍需选择使用共享版本或合并本机会话，不会静默覆盖本机。
3. 日常使用：启动、切回应用、保存修改时同步，并每分钟检查。可通过“会话 → 立即同步共享数据”手动执行。内容未变化时不重写配置。
4. 将“同步方式”改为“不启用同步”并应用可停用；本地配置和已有共享文件保留。

“同步方式”只能选择一种：不启用同步、同步目录、WebDAV。页面只显示当前方式的配置。切换方式后点击“应用”，程序会自动停用原方式，无需分别开关；取消设置则保持原方式。

每台 Mac 的同步目录地址和加密同步基准保存在本地，不会传到另一台设备。同步前按照上次基准比较本机与共享版本：不同会话的修改自动合并，同一会话双方修改时由用户选择。同步文件意外删除、格式损坏、主密码不匹配、iCloud 占位文件未下载时停止同步，保留本地副本，不用空配置覆盖。

“同步完成”表示 OShell 已和本机的共享目录文件完成读写，**不代表 iCloud 已上传到云端**；请在切换设备前确认 Finder 的同步状态。目录写入使用文件协调和内容版本校验，但不能提供跨设备的实时锁。如果 iCloud 已生成文件级冲突版本，OShell 会停止覆盖，需先保留并处理这些副本。不同电脑轮流使用时仍应等待云端同步完成。

**旧版本升级：** 已直接使用 iCloud / 自定义数据目录的配置，在新版首次启动输入主密码后迁回本地工作副本，原共享目录继续作为同步位置。旧本地配置保存在本地 `storage-backups` 中，原共享数据不删除。首次迁移必须能读取原共享目录；此后离线启动只依赖本地副本。请让参与共享的 Mac 都使用支持本地副本的版本。

### WebDAV

WebDAV 同样使用本地加密工作副本。在“同步方式”中选择 WebDAV 后，再填写服务器配置。

1. 准备可读写的 WebDAV 父目录，可使用 **HTTP 或 HTTPS** 地址，建议 HTTPS。HTTPS 默认按 macOS 系统规则验证证书。
2. 打开“设置 → 多设备同步”，将“同步方式”设为 WebDAV，填写目录地址、账号及密码（服务商要求时使用应用专用密码）。
3. 可先点击“测试连接”。遇到自签名或私有 CA 证书时，可点击“信任此服务器证书…”，核对服务器、主体、颁发者、有效期与 SHA-256 指纹，选择“信任并重试”；最后点击设置页“应用”保存。地址必须是最终目录地址，不跟随重定向。
4. 自动检查该目录下的 `oshell/`：已存在就复用，不存在则创建，并将同步文件保存为 `oshell/oshell-vault.json`。如果填写的地址已经以 `oshell/` 结尾（兼容 `OShell/`），直接使用该目录，不重复嵌套。测试连接会准备目录，并显示实际同步路径；点击“应用”后启用同步。远端已有数据时选择使用共享版本或合并本机会话。其他 Mac 使用相同主密码配置同一位置。

兼容旧位置：如果填写的目录中已经直接存在 `oshell-vault.json`，继续使用原位置，不自动搬迁或删除文件。与尚未自动选择子目录的 oshell-desktop 共用新位置时，在 Desktop 中填写实际的 `…/oshell/` 地址。服务器需允许创建目录（MKCOL）；同名普通文件、无权限或无效目录响应会报错，不会覆盖数据。父目录须先存在，程序只创建一层 `oshell`。
5. 离线修改在本地保存，联网后重新比较并同步；自动同步失败仅更新状态，不弹窗打断终端，手动同步时显示具体错误。

使用 `http://` 时，WebDAV 账号密码会明文传输；会话数据文件仍由主密码加密，主密码仍是开启同步的必要条件。设置页会显示 HTTP 提示，不显示证书信任操作。HTTP 建议仅用于可信网络；HTTPS 不会自动降级成 HTTP，重定向仍会拒绝，请填写最终地址。

证书信任只绑定当前域名/IP、端口和这张证书，随本机 WebDAV 登录设置加密保存，不写入共享会话文件，也不修改系统钥匙串。证书更换需重新确认；过期或尚未生效不能直接信任。使用 IP 地址直连时，证书缺少 HTTPS 服务端用途标记或名称不匹配，可在确认指纹后为该 IP、端口和这张证书建立专用信任；其他域名/端口和其他证书不受信任。点击“取消证书信任”并应用，可恢复系统校验；取消整个设置窗口不会保存信任更改。其他设备需独立配置证书信任。

WebDAV 登录信息和同步基准也使用主密码加密，分别保存在本地 `webdav-settings.json` 与 `webdav-baseline.json` 中。服务器必须支持强 ETag 和条件写入：创建使用 `If-None-Match: *`，更新使用 `If-Match`，HTTP 412 时停止覆盖并重新比较。协议依据 [RFC 4918](https://www.rfc-editor.org/rfc/rfc4918.html) 和 [RFC 9110 的 If-Match](https://www.rfc-editor.org/rfc/rfc9110.html#name-if-match)。

同步启用或有待生效设置时不能清除或修改主密码。需先停用同步并取消待生效设置，再调整主密码；更换主密码后请使用新的同步目录重新建立共享，原共享文件仍由原密码保护。

### 同步状态与本地诊断日志

窗口头部“更新”按钮旁的同步图标实时反映多设备同步状态：灰色表示未启用或已取消，蓝色表示等待或正在同步，绿色表示最近一次同步完成，橙色表示需处理错误、冲突或解锁主密码。图形也会随状态变化，外围细圆环在同步时旋转，成功后显示绿色完整圆环约两秒；失败、等待确认或取消时停止旋转。圆环表示当前正在同步，不代表字节传输百分比；启用系统“减少动态效果”时使用静态圆弧。悬浮可查看实际执行阶段和最近成功时间。没有打开 SSH 会话时也可点击，打开独立的“配置同步”状态窗口。点击“立即同步”即可使用已保存的配置开始一次同步，自动或手动模式均可使用；“同步配置…”进入多设备同步设置。多个窗口共享同一状态与同步任务。

“设置 → 多设备同步”顶部始终显示同步状态卡片，无需展开或滚动到底部；显示当前已保存的同步方式、执行阶段、最近尝试和成功时间、耗时、本地待同步修改、错误、当前策略与下一次自动检查 / 重试时间。成功时间保存在本机，重启后仍可查看；更换同步位置或 WebDAV 连接配置后重新统计，避免把旧目标的成功当作新目标的成功。目录模式的成功仅表示已与本机同步目录文件对齐，不代表 iCloud 云端上传已经完成。

同步成功或配置没有变化时不再弹出确认框，结果更新到头部图标和状态卡片。自动失败仍不打断终端；手动失败显示错误，首次接入和冲突选择继续保留。锁定时卡片提供“解锁主密码…”操作。

状态窗口和设置卡片显示阶段进度条：读取、加密上传或应用期间显示动画，完成后显示满格；失败、取消或等待确认会停止动画并保留对应提示。进度条表示操作阶段，不显示估算的传输百分比，也不代表 iCloud 云端上传进度。同步期间不能重复启动，支持“取消本次”；关闭状态窗口不会中断同步。

设置页中的“关闭设置后同步”会安排一次手动检查，关闭设置后使用已保存的配置执行；它不会自动应用未保存的设置。“取消本次”可取消正在执行或已安排的操作，本地修改保留，后续按已保存策略检查。设置打开时暂停新的检查，并推迟应用正在读取的共享结果，避免覆盖正在编辑的设置。

“查看日志…”显示本机最近的同步过程，“导出诊断日志…”保存可用于排查的 JSON 文件；日志窗口支持清空。日志记录时间、同步方式、阶段、结果、耗时、随机操作编号和 HTTP / 系统错误代码，导出时附带应用及系统版本，**不记录密码、Token、账号、服务器地址、目录路径或会话内容**。日志无法写入时会在状态卡片提示，同步功能仍继续运行。

诊断数据位于本机默认数据目录的 `logs/sync.json`，不进入 iCloud 或 WebDAV 同步包。仅当前用户可读写，最多保留 7 天、2000 条、1 MiB，以先达到的限制为准。长期无变化的自动检查会减少过程日志，仍刷新最近成功时间。清空日志不删除会话、同步基准或最近成功时间；导出只包含经过筛选的事件，不包含本地配置指纹。

### 处理会话同步冲突

冲突通过会话 UUID 识别，不按名称匹配。窗口左侧列出待确认项目，右侧对照两个版本；密码只提示是否改变，不显示明文或密文。所有冲突均选择后才可确认保存。目录、代理和快捷引用发生双向改动时，会作为单独项目确认；客户端设置等类别仅在勾选同步后参与比较及冲突确认。

选择“稍后处理”或按 Esc 保留本机离线修改和旧同步基准，本次运行暂停自动弹出冲突。之后通过“会话 → 处理同步冲突…”或“立即同步共享数据”继续比较。确认期间共享文件再次变化时拒绝覆盖，需要重新确认。

如果检测到本地工作文件也被其他进程修改，则保存本机草稿到本地 `sync-conflicts`，暂停同步并由“处理同步冲突…”解决；这些草稿不会随共享数据传输。需要丢弃草稿时，可选择“放弃本机同步草稿…”，确认后重新载入。共享主密码不同或已改变时不会自动合并。

## 左侧会话列表

头部栏最左侧的“会话列表”按钮、菜单“视图 → 会话列表”或 **⌘⇧B** 可显示/隐藏左侧目录树；在“设置 → 快捷键”中可修改该组合键，并检查冲突。侧栏的关闭按钮也可隐藏列表。显示状态会作为新窗口及下次启动的本机默认状态，当前其他窗口不受影响；专注全屏期间暂时隐藏，退出后恢复。

列表与会话管理使用同一份数据，展示目录、实际会话以及 `/Links` 快捷引用。双击目录展开/折叠，双击会话或选中后按回车连接；SFTP / FTP 会话沿用文件管理入口。搜索支持会话名称、主机/IP、用户名、端口及目录，多个关键词按“全部包含”匹配，保留匹配项的父目录。搜索框按向下键进入结果，回车连接首个结果；Esc 清空搜索。清空搜索后恢复原来的目录展开状态。

左侧会话栏搜索框下方提供“全部展开”和“全部收缩”，右键菜单中也可使用。操作覆盖多层目录；搜索时仅展开或收缩当前结果，不改变清除搜索后的原展开状态。

侧栏显示状态和侧栏快捷键只保存在本机，不写入跨客户端共享配置；已有自定义组合键优先，不会被新增默认快捷键覆盖。

## 文件管理传输记录

文件管理底部的“传输记录”按钮可展开或隐藏当前文件标签的上传、下载列表，确认开始传输时自动展开。记录包含时间、方向、文件或目录、方式、传输量及结果；双击记录查看本地/远程路径、开始/结束时间和失败说明。重名自动编号后，记录显示实际使用的目标路径。

每个选中的文件或目录记为一个项目，目录包含其递归传输的子项；不把某个子文件的进度误当作整个目录的大小。批次中已成功的项目保留成功状态，失败项与尚未执行的项目分别标识。SCP 没有逐字节进度时显示“—”，结果仍会记录。

各文件标签独立保存本次运行的记录，同一标签重连时保留，更换会话或关闭标签后清除。最多保留最近 500 条已结束记录，待执行及传输中项目额外保留；“清空已结束”不会删除正在传输的记录。记录仅存在内存，不写入配置、日志文件或 iCloud / WebDAV；此列表记录文件管理发起的传输。

## SFTP 断点续传

文件管理中，SFTP **普通文件**上传和下载支持断点续传。在底部“传输记录”中使用：

- **暂停**：暂停当前文件，保留已传片段；当前批次后续项目标为“未执行”，需要重新选择传输。
- **继续**：选中“已暂停”的记录，自动重连后校验片段并继续该文件。
- **重试**：选中失败或取消的可续传记录，校验后从断点重试。不会直接覆盖或从头改写目标。

上传和下载先写入目标目录中的 `.oshell-part-*` 临时文件，成功后才改为最终文件名。传输详情显示临时片段路径。继续前会比对源文件大小、修改时间以及已传片段的完整内容；源文件变化、片段不一致、符号链接替换或目标已经存在时拒绝续传，原片段保留。大文件的校验需要读取已传内容，可能耗时，期间可再次暂停。

续传记录和校验状态仅保存在当前文件管理标签的内存中；重连不会丢失，关闭标签、退出程序、更换连接或清除失败记录后不能自动恢复该任务。未完成的临时文件不会自动删除，可依据详情中的路径手动清理。目录、FTP、SCP 暂不支持续传，对应按钮不可用；不适用续传的传输仍保留原有行为。

### 根目录置顶

在会话管理或左侧会话栏中，右击根目录下的会话或目录，选择“置顶”；再次右击可“取消置顶”。可同时选中多个根目录项目批量操作，混合已置顶与未置顶项目时统一置顶。置顶项集中显示在最前面，区内仍按目录优先、名称排序；取消后恢复原排序。子目录中的项目不提供置顶操作。

置顶偏好仅保存在本机，所有窗口一致，不同步、不改目录名称。目录重命名保留置顶；删除或移入子目录后清除置顶。Links 根目录也可置顶，快捷引用本身不支持根目录置顶。

### 关闭标签确认

在“设置 → 标签”中配置“关闭标签前确认”，点击“应用”后所有窗口立即生效，默认开启。标签关闭按钮、右键关闭、关闭标签快捷键和关闭分屏均遵循此设置：仍有连接或进程时确认，空白或已结束的标签直接关闭。取消勾选后关闭标签或分屏会立即结束其中的会话，不再弹出确认。关闭整个窗口、退出程序及重新连接的确认独立保留。此偏好仅本机保存，不参与共享配置同步。

### 全心专注

在“视图”、工具菜单或标签栏右键菜单切换“全心专注”，也可按 **⌃⇧⌘F**。开启后进入专注全屏，保留标签栏与终端，隐藏各分屏上方的会话小标题和底部快捷发送栏。再次切换只恢复这两处区域、保留全屏；退出专注全屏则恢复普通布局。草稿、分屏和连接保持，Esc 继续供终端程序使用。开关仅影响当前窗口，不同步、不改动发送栏的保存偏好；若该快捷键已被自定义功能占用，优先使用已有绑定，可从菜单切换。

### 本地终端与 Links 目录

从顶部“本地”按钮打开本地终端，无需预先保存会话。新配置不再自动创建“本机 / 本地终端”。旧配置中未修改且未被快捷引用使用的默认本地项在会话管理、侧栏和快捷连接中隐藏，原始数据及导出 / 同步仍保留；重命名、修改过的本地会话及已有引用继续显示。“本机”中若还有其他会话或子目录，也会继续显示。Links 根目录使用带链环角标的文件夹，与普通目录区分。

### 图片粘贴（Codex / OpenCode 等终端程序）

复制截图或单张图片文件后，在终端按 **⌘V**、使用菜单粘贴或右键粘贴。OShell 会显示图片尺寸、大小和目标，确认后将图片路径粘贴到当前终端，不自动回车，也不参与同步输入广播。普通文本粘贴保持原行为。

- 可在确认框勾选“不再提醒”：本地终端对当前 Mac 的所有本地标签生效；SSH 仅对该会话生效并记住远端图片目录。新建或复制的会话，以及主机、端口、用户名、跳板或代理配置变化后会重新询问；与正在运行 Codex CLI、OpenCode 或其他程序无关。只有成功粘贴后才记住，取消或失败不保存选择。
- 在“设置 → 常规 → 图片粘贴提醒…”中可取消本地免确认、逐个恢复 SSH 提醒，或选择“恢复全部提醒”；点击设置窗口“应用”后生效，取消不保存。记录位于本机 `image-paste-settings.json`，不进入共享配置、导出文件或多设备同步。SSH 上传进度与取消操作仍会显示，恢复提醒不会删除已保存或上传的图片。
- 本地终端：图片转换为 PNG，保存在本机数据目录的 `clipboard-images` 私有缓存中，供本地程序读取。
- 已连接的 OShell SSH 会话：复用原认证连接，通过 SFTP 上传。默认在服务器 `/tmp` 下建立独立私有目录，可在确认框中改为项目目录。上传完成才发送远端路径；失败、取消或目标断开时不发送路径。
- 图片文件及转换后的 PNG 最多 20 MiB，剪贴板原始位图最多 160 MiB、4000 万像素（支持较大的 Retina TIFF 截图）。本地缓存最多 200 MiB，超过 7 天的图片在下次图片粘贴时清理；需要长期使用请另行保存。远端成功上传的图片不会由 OShell 自动删除；关闭会话也不会删除，需手动清理或由服务器的临时目录策略处理；取消或断线时可能残留未完成的私有临时目录。
- 服务器需允许 SFTP。终端内再次执行 ssh、进入容器、切换用户或使用独立远程服务时，程序可能无法访问当前 SSH 主机的文件路径；此时应使用对应的 OShell SSH 会话，或选择程序可访问的共享目录。此功能不授予远端读取 Mac 剪贴板的权限。

## AI 助手（首版）

点击头部 **AI** 或按默认 **⌃⌥A** 打开右侧助手。面板可拖动分隔线调整宽度，窄窗口自动使用独立窗口；“收起”保留对话与草稿。每个终端分屏独立对话，跨窗口迁移沿用原会话；主机或已识别的工作目录变化时重新建立分析上下文。旧对话可从本机历史查看。后台回复完成后，对应标签和 AI 按钮显示未读提示，打开对应分屏的助手后清除。

在“设置 → AI”可先选择**渠道预设**，自动填入接口类型、完整地址、模型和输出 Token 上限，再填写对应密钥。已有配置默认保持“自定义”，不会自动切换渠道。

| 渠道预设 | 默认接口 | 默认模型 |
| --- | --- | --- |
| Kimi Code · 国内 / 国际 | `https://api.kimi.com/coding/v1/messages` / `https://api.kimi.ai/coding/v1/messages` | `kimi-for-coding` |
| DeepSeek | `https://api.deepseek.com/chat/completions` | `deepseek-flash` |
| MiniMax · 国内 / 国际 | `https://api.minimax.cn/anthropic/v1/messages` / `https://api.minimax.io/anthropic/v1/messages` | `MiniMax-M3.1-Flash` |
| GLM · 标准 API | `https://open.bigmodel.cn/api/paas/v4/chat/completions` | `glm-5.3` |
| GLM · Coding Plan | `https://open.bigmodel.cn/api/coding/paas/v4/chat/completions` | `glm-5.3` |

选择另一个非自定义预设会清空旧密钥，并关闭图片支持，防止串用账号或沿用上一模型的图片能力；重新选择同一预设保留编辑内容，切回“自定义”保留当前地址、模型与密钥。模型和地址仍可修改；预设只是参数配置，不验证服务身份，发送以授权窗口显示的实际地址为准。按模型能力开启图片后，仍需批准具体图片。

渠道预设默认输出上限为 16384 tokens；旧配置保持 4096。可在“输出 Token 上限”中设置 256～65536，推理过程也可能计入该上限；若返回截断提示，可缩小问题或调高上限。DeepSeek、GLM 等预设的 Chat Completions 使用 `max_tokens`，不携带未声明支持的 `store` 扩展字段。自定义 OpenAI 格式继续使用 `max_completion_tokens`。这些参数也会进入冻结预览，改变渠道或输出上限会使旧授权失效。

Kimi Code 专用密钥与普通 Kimi 开放平台密钥不通用。GLM 标准 API 与 Coding Plan 的端点和密钥分别配置；Coding 套餐能否供 OShell 使用，以服务方对账号、模型和客户端的授权为准。请求以真实 `OShell/版本号` 标识客户端，遇到权限拒绝不会伪装其他工具或自动切换付费渠道。上述预设依据 [Kimi Code 文档](https://www.kimi.com/code/docs/)、[DeepSeek API](https://api-docs.deepseek.com/)、[MiniMax 国内文档](https://platform.minimax.cn/docs/api-reference/text-anthropic-api)、[MiniMax 国际文档](https://platform.minimax.io/docs/api-reference/text-anthropic-api)、[GLM 标准 API](https://docs.bigmodel.cn/cn/api/introduction) 和 [GLM Coding 接入说明](https://docs.bigmodel.cn/cn/coding-plan/tool/others)（核对日期 2026-10-23）；模型可用性仍取决于账号权益。

不使用预设时，也可直接选择**接口类型**并填写完整地址：

| 类型 | 地址示例 | 鉴权 |
| --- | --- | --- |
| OpenAI 兼容 · Chat Completions | `https://api.openai.com/v1/chat/completions` | `Authorization: Bearer` |
| OpenAI · Responses | `https://api.openai.com/v1/responses` | `Authorization: Bearer` |
| Anthropic · Messages | `https://api.anthropic.com/v1/messages` | `x-api-key`，固定 `anthropic-version: 2023-06-01` |
| Gemini · generateContent | `https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent` | `x-goog-api-key` |

可替换为提供对应原生协议的网关地址。Gemini 的 `{model}` 在授权前替换为“模型”字段，并在预览中显示真实请求地址；也可填写模型固定的完整地址，但必须与“模型”一致。密钥不要放在 URL 查询参数中。Gemini 使用 Developer API 的 API Key 鉴权，本版不包含 Vertex AI OAuth 或云平台专有鉴权。

原有配置默认保持 Chat Completions。切换类型只更新填写提示，不自动修改现有地址或密钥、不发请求；类型变化也使旧授权失效。AI 本机设置保存为内部格式 v3，兼容读取 v1/v2；没有接口类型的旧配置使用 Chat Completions，没有渠道和输出上限的旧配置保持自定义与 4096 tokens；不认识类型或版本时拒绝加载，旧版程序不会把新接口配置误读成兼容接口。此内部格式与 App 版本号、共享配置协议独立。

本机服务可使用 `http://localhost:端口/...` 或回环 IP；其他服务要求 HTTPS。四种类型均支持非流式文字与图片输入，图片能力需按模型实际支持情况启用。测试连接会先展示固定测试内容并请求一次授权，不附加终端内容。可选填写接收方、租户/项目和模型路由说明；这是用户声明，回环地址或 HTTPS 不能证明服务不会转发或保留数据。

四种接口都只发送当次批准的快照。自定义 OpenAI 两种格式和 Gemini 请求显式设置 `store: false`，不使用服务端会话 ID、自动续聊、缓存引用或不透明推理内容；这不是服务端零留存承诺。工具调用、被拦截或截断的响应不会当作完整命令展示，也不会自动执行或重试。接口定义依据 [OpenAI Docs：Responses](https://developers.openai.com/api/docs/guides/migrate-to-responses)、[Anthropic Messages](https://platform.claude.com/docs/en/api/messages/create) 和 [Gemini generateContent](https://ai.google.dev/api/generate-content)。

三个入口分别面向故障排查、编写命令和解释命令。选中终端内容后可右键“用 AI 分析所选内容”或“用 AI 解释命令”；启用了右键粘贴时用 Shift+右键打开菜单。点击“添加上下文”可附加选中文字、当前屏幕、最近 100/300/1000 行、图片或 UTF-8 文本文件，也可向 AI 输入框粘贴/拖入单张图片。快照在添加时获取，不持续上传终端输出；超限截取会标明。单张图片最多 4 MiB，单次请求图片总计最多 8 MiB；模型需支持图片。

点击“选择发送范围”或“审阅并发送”（⌘↩）打开授权窗口：

- 默认仅勾选本次问题和主动添加的附件；会话名称、主机/IP、账号、目录、代理等字段逐项选择，默认均不发送。
- 对话历史、旧附件和旧图片默认不重复发送。需要连续分析时，明确选择历史资料；历史 AI 回答只有在其全部依据也获准时才能发送。
