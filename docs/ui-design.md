# UI 风格与设计理念

OShell 采用克制、内容优先的 macOS 原生桌面风格。终端内容是视觉主体，工具栏负责提供清晰、稳定的操作入口。新功能与界面修改应遵循本文；交互能力不能因视觉简化而被删除。

## 原生控件与视觉层级

- 优先使用 AppKit 控件、系统字体、SF Symbols 和语义颜色，保留系统键盘导航、焦点反馈、菜单行为与辅助功能支持。
- 工具栏默认不显示每个按钮的外框或实心底板。用位置、留白和少量组间分隔线组织功能，不给每个图标再套一层装饰边框。
- 普通工具栏按钮在悬停、按下或选中时提供原生反馈；开关状态必须可辨认。下拉按钮始终保留箭头，菜单展开时使用系统菜单反馈。
- 表单中的确认、取消等操作仍使用标准按钮；输入框保留输入边界。工具栏的轻量样式不应全局覆盖所有控件。
- 深色和浅色外观都使用系统语义色。颜色表达状态，不能是唯一提示：录制、同步、代理等同时提供图标变化、提示文字或菜单状态。禁用操作保持系统的弱化外观。

## 头部工具栏

当前实现位于 `WorkspaceController.buildInterface`、`WorkspaceToolbar.swift` 和 `SessionPropertiesControl.swift`。

| 项目 | 约定 |
| --- | --- |
| 工具栏高度 | 40 pt，控件垂直居中 |
| 普通按钮命中区域 | 高 28 pt、宽至少 28 pt；不因图标小而缩小点击区域 |
| 图标与文字 | 常规图标为 14 pt regular 的 SF Symbols；文字为 12 pt 系统字体；组合图标按视觉重量校准 |
| 间距 | 控件间距 8 pt，左右边距 8 pt；只在功能组之间使用分隔线 |
| 普通按钮 | AppKit accessory bar 样式，仅交互或选中时突出显示，不显示常驻边框 |
| 下拉按钮 | 无边框的原生 `NSPopUpButton`，保留可见箭头，不把整个按钮伪装成单一动作 |
| 会话属性 | 无边框分体按钮；主体编辑当前会话，箭头展开当前、默认和其他会话菜单 |

按用户工作顺序组织工具栏：会话入口 → 布局 → 搜索与工具 → 弹性留白 → 属性和应用级操作。图标应表达动作对象，避免多个意义相近的齿轮按钮缺少区分。图标按钮须提供明确的辅助功能名称和悬停提示；菜单使用清楚的文字。

快捷连接菜单用协议图标区分 SSH、SFTP、FTP 等类型，条目文字只显示会话名称，不再追加“· SSH”等重复的协议后缀。

窗口足够宽时显示主要操作的文字，空间收紧时先保留图标。达到极简窗口条件时收起整个工具栏，不出现横向滚动条；恢复时保留阈值余量，避免临界尺寸来回闪动。相关入口仍可通过菜单和已有快捷键访问。具体阈值以 `WorkspaceToolbarHost` 为准。

## 交互与资源使用

- 视觉调整不改变点击、右键、Option 点击、快捷键、开关语义及菜单验证规则。选择其他会话的属性只编辑配置，不隐式连接或切换标签。
- 保留清楚的键盘焦点、禁用状态和足够的命中区域。图标不能替代辅助功能名称，颜色不能替代文字说明。
- 优先复用系统控件的交互反馈；不为悬停添加轮询定时器、持续动画或整窗刷新。模板图标复用缓存，不在每次布局时重新生成。
- 动画只用于有意义的状态反馈，并尊重减少动态效果设置。避免仅为装饰引入大面积模糊、额外渲染表面或持续 GPU 工作。
- 终端配色与应用界面外观独立；本机窗口呈现规则不应改变共享配置协议。

## 修改后的验收

检查深色和浅色、普通与禁用、悬停与按下、开关选中、菜单展开和键盘焦点。检查有文字、仅图标及极简窗口下的布局，确认不重叠、不裁切、不横向滚动。会话属性主体与箭头分别验证；同步进度、录制和代理状态仍须易读。

使用独立测试应用和合成会话。优先检查真实窗口截图；离屏位图可能遗漏 AppKit 原生控件内容，锁屏测试不能替代实屏视觉验收。运行与改动相关的现有 UI 回归，不把视觉修改扩展为无关功能重构。

参考 Apple 的 [Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars)、[Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons) 和 [NSButton 悬停边框行为](https://developer.apple.com/documentation/appkit/nsbutton/showsborderonlywhilemouseinside)。本文中的尺寸和排列属于 OShell 项目约定，不代表 Apple 的统一强制规格。
